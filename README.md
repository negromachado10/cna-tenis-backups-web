# CNA Tenis Backups — información pública

Sitio institucional estático que describe la herramienta interna de respaldos
cifrados de la plataforma de reservas de tenis del Club Náutico Arrecifes.

## Publicación

Habilitar **Settings → Pages → Deploy from a branch → main → /(root)**.
No requiere Jekyll, Node, Actions personalizada ni servicios pagos.

- Inicio: https://negromachado10.github.io/cna-tenis-backups-web/
- Privacidad: https://negromachado10.github.io/cna-tenis-backups-web/privacidad.html
- Términos: https://negromachado10.github.io/cna-tenis-backups-web/terminos.html

Los enlaces solo funcionan cuando GitHub Pages haya terminado de publicar.

Este repositorio es **público**. No agregar claves, tokens OAuth, archivos
de respaldo, secretos de Supabase ni datos de los socios.

## Alcance
Contenido informativo y legal, sin formularios, analítica propia ni inicio de sesión.
El proyecto de backups real sigue en el repositorio privado de CNA Tenis y
no debe confundirse con esta web pública.

**Importante:** Google OAuth puede requerir verificar la propiedad del dominio
mediante Search Console. Disponer de una página de GitHub Pages no significa
automáticamente que el dominio quede aprobado por Google.
